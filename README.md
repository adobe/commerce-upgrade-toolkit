# Adobe Commerce Upgrade Toolkit

An AI-assisted toolkit for Adobe Commerce / Magento 2 version upgrades.
**GitHub Copilot is the primary agent**, supported in **VS Code and Copilot CLI**.
Claude Code is also supported.

The toolkit helps you plan upgrade hops, scan compatibility, fix findings,
validate changes, and prepare a deployment runbook. Developers review and
approve the work; it does not deploy production automatically.
